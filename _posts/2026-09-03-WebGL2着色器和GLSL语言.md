## 点着色器

点着色器的工作是生成裁剪空间坐标（-1～1），总是采用 gl_Position = ... 的形式将裁剪空间的点坐标赋值给内置变量gl_Position缓存在WebGL内部

点着色器获得数据的方式有三种：

1. 属性（从缓冲区读）
2. Uniforms（单次绘制过程中，对于所有顶点的值都是一样的）
3. 纹理（来自pixels/texels）

### 属性

vertex sharder写法

```glsl
#version 300 es
in vec4 a_position;
void main() {
  gl_Position = a_position;
} 
```

在sharder中，没有对js中传过来的坐标做任何数学计算，直接放在WebGL缓存中他就能正常工作了。这是因为js中传过来的坐标本身就是(
-1~1)区间内的坐标，与裁剪坐标吻合。

在js中调用API创建缓冲区

```javascript
const buffer = gl.createBuffer()
```

将数据上传到缓冲区

```javascript
gl.bindBuffer(gl.ARRAY_BUFFER, buffer)
gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([...]), gl.STATIC_READ)
```

查找程序中属性的位置

```javascript
const attLocation = gl.getAttribLocation(program, "a_xxx")
```

告诉WebGL属性如何从缓冲区取值

```javascript
gl.enableVertexAttribArray(attLocation)
gl.vertexAttribPointer(attLocation, numOfComponents, type, false, 0, 0)
```

属性的类型可以是 float, vec2, vec3, vec4, mat2, mat3, mat4, int, ivec2, ivec3, ivec4, uint, uvec2,
uvec3, uvec4.

### Uniforms

对于所有顶点在调用着色器的时候，uniforms的值都是一样的。

```glsl
#version 300 es
in vec4 a_position;
uniform vec2 u_offset;

void main() {
  gl_Position = vec4(a_position.x + u_offset.x, a_position.y - u_offset.y, a.position.zw);
}
```

在javascript中给unifrom变量赋值

```javascript
const offsetLocation = gl.getUniformLocation(program, "u_offset")

gl.uniform2fv(offsetLocation, [0.1, 0.3])
```

uniforms可以是各种不同的类型，每种赋值的方法都不一样

```javascript
gl.uniform1f(floatUniformLoc, v);                 // for float
gl.uniform1fv(floatUniformLoc, [v]);               // for float or float array
gl.uniform2f(vec2UniformLoc, v0, v1);            // for vec2
gl.uniform2fv(vec2UniformLoc, [v0, v1]);          // for vec2 or vec2 array
gl.uniform3f(vec3UniformLoc, v0, v1, v2);        // for vec3
gl.uniform3fv(vec3UniformLoc, [v0, v1, v2]);      // for vec3 or vec3 array
gl.uniform4f(vec4UniformLoc, v0, v1, v2, v4);    // for vec4
gl.uniform4fv(vec4UniformLoc, [v0, v1, v2, v4]);  // for vec4 or vec4 array

gl.uniformMatrix2fv(mat2UniformLoc, false, [4x element array])  // for mat2 or mat2 array
gl.uniformMatrix3fv(mat3UniformLoc, false, [9x element array])  // for mat3 or mat3 array
gl.uniformMatrix4fv(mat4UniformLoc, false, [16x element array])  // for mat4 or mat4 array

gl.uniform1i(intUniformLoc, v);                 // for int
gl.uniform1iv(intUniformLoc, [v]);                 // for int or int array
gl.uniform2i(ivec2UniformLoc, v0, v1);            // for ivec2
gl.uniform2iv(ivec2UniformLoc, [v0, v1]);          // for ivec2 or ivec2 array
gl.uniform3i(ivec3UniformLoc, v0, v1, v2);        // for ivec3
gl.uniform3iv(ivec3UniformLoc, [v0, v1, v2]);      // for ivec3 or ivec3 array
gl.uniform4i(ivec4UniformLoc, v0, v1, v2, v4);    // for ivec4
gl.uniform4iv(ivec4UniformLoc, [v0, v1, v2, v4]);  // for ivec4 or ivec4 array

gl.uniform1u(intUniformLoc, v);                 // for uint
gl.uniform1uv(intUniformLoc, [v]);                 // for uint or uint array
gl.uniform2u(ivec2UniformLoc, v0, v1);            // for uvec2
gl.uniform2uv(ivec2UniformLoc, [v0, v1]);          // for uvec2 or uvec2 array
gl.uniform3u(ivec3UniformLoc, v0, v1, v2);        // for uvec3
gl.uniform3uv(ivec3UniformLoc, [v0, v1, v2]);      // for uvec3 or uvec3 array
gl.uniform4u(ivec4UniformLoc, v0, v1, v2, v4);    // for uvec4
gl.uniform4uv(ivec4UniformLoc, [v0, v1, v2, v4]);  // for uvec4 or uvec4 array

// for sampler2D, sampler3D, samplerCube, samplerCubeShader, sampler2DShadow,
// sampler2DArray, sampler2DArrayShadow
gl.uniform1i(samplerUniformLoc, v);
gl.uniform1iv(samplerUniformLoc, [v]);
```

### 纹理

```glsl
#version 300 es

in vec3 aPosition;
in vec2 aTexCoord;

uniform sampler2D uHeightMap;
uniform mat4 uMVP;

out vec2 vTexCoord;

void main() {

    float height = texture(uHeightMap, aTexCoord).r;

    vec3 position = aPosition;

    position.y += height;

    gl_Position = uMVP * vec4(position, 1.0);

    vTexCoord = aTexCoord;
}
```

## 片段着色器

片段着色器的工作是给栅格化的片段提供颜色。

```glsl
#version 300 es
precision highp float;

out vec4 outColor;
void main() {
  outColor = doMathToMakeAColor;
}
```

每个片段都会调用一次片段着色器。

片段着色器获取数据的方式有三种：

1. Uniforms
2. 纹理
3. Varying

其中uniforms和纹理与顶点着色器相似。varying是用来从顶点着色器往片段着色器传值的。
vertexShader中

```glsl
out vec4 v_color;
void main() {
  v_color = ...;
}
```

fragmentshader中

```glsl
in vec4 v_color;
out vec4 outColor;
void main() {
  outColor=v_color;
}
```

## GLSL

GLSL 全称是图形库着色器语言. 它是一种编写着色器的语言。它有一些在 Javascript 中不常见的特性。它主要被设计用来执行数学计算，以对图形进行光栅化。
因此，它内置了 vec2, vec3 和 vec4 之类的类型，分别表示 2 维，3 维和 4 维向量。类似也有mat2, mat3和mat4， 分别表示 2X2, 3X3 和
4X4的矩阵。你可以执行一些操作，如将vec乘以标量。

```glsl
vec4 a = vec4(1, 2, 3, 4);
vec4 b = a * 2.0;
// b is now vec4(2, 4, 6, 8);
```

类似地，它可以执行矩阵乘法运行和向量与矩阵的乘法运行

```glsl

mat4 a = ???
mat4 b = ???
mat4 c = a * b;

vec4 v = ???
vec4 y = c * v;
```

同时，它有选择向量不同部分的选择器。对于vec4,

vec4 v;
v.x与 v.s、v.r和v[0]的意思一样.
v.y与 v.t、v.g 和 v[1]的意思一样.
v.z 与 v.p、 v.b 和 v[2]的意思一样.
v.w 与 v.q 、 v.a 和 v[3]的意思一样.
